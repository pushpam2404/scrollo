# Security Policy

## What Scrollo can access

Scrollo needs **Accessibility** access to receive scroll events and to read the scroll position of other apps. It uses a **listen-only** event tap: it cannot modify, block or inject input. It makes **no network connections**, stores no input, and does not use Screen Recording or Input Monitoring.

## Reporting a vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/pushpam2404/scrollo/security/advisories/new) instead of a public issue. Include the version, macOS version, and steps to reproduce. You can expect an acknowledgement within a few days.

## Supported versions

Only the latest release receives fixes.
