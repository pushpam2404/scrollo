## Scrollo 1.0.1

### Changed
- Removed the notch equalizer and its settings. Scrollo is now sounds and haptics only.

Everything else is unchanged from 1.0.0: ten click sounds, edge-aware clicking, five-level trackpad haptics, adjustable volume, spacing and output device. Universal binary (Apple Silicon and Intel), macOS 14 or later.

### Install
1. Download **Scrollo-1.0.1.dmg** below and drag Scrollo into Applications. Replace the old copy if you have one.
2. The app is not notarized: open **System Settings → Privacy & Security → Open Anyway** once (or run `xattr -dr com.apple.quarantine /Applications/Scrollo.app`).
3. Allow **Accessibility** when prompted. If you are upgrading, your existing permission is kept.
