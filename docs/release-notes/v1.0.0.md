## Scrollo 1.0.0

The first release: satisfying clicks for every scroll on your Mac.

### Highlights
- **Ten click sounds**, real recordings, trimmed and level-matched, with subtle pitch variation.
- **Edge-aware**: silent at the top and bottom of a page, while rubber-banding, and over the empty desktop. Learned per app.
- **Trackpad haptics** in five strengths (Force Touch trackpads).
- **Notch equalizer** beside the notch while you scroll.
- Adjustable volume, click spacing (50 to 500 px), momentum behavior and output device.
- Universal binary: Apple Silicon and Intel, macOS 14 or later.

### Install
1. Download **Scrollo-1.0.0.dmg** below and drag Scrollo into Applications.
2. The app is not notarized: open **System Settings → Privacy & Security → Open Anyway** once (or run `xattr -dr com.apple.quarantine /Applications/Scrollo.app`).
3. Allow **Accessibility** when prompted.

### Notes
- Works in apps that report their scroll position (Preview, TextEdit, Finder, Terminal, Microsoft Word, and most native apps). Browsers and web-based apps such as Spotify and WhatsApp do not, so Scrollo stays silent there unless you opt in under *Settings → Behavior*.
- It is a native Mac app. It does not run on Windows or Linux.
